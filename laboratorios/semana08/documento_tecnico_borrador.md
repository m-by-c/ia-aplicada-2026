# Detección de incendios en edificios inteligentes

## 1. Introducción

El proyecto Detección de incendios en edificios inteligentes tiene como objetivo contribuir a la prevención de incendios mediante el uso de inteligencia artificial enfocada en la detección de humo. La solución está dirigida a los inquilinos de edificios inteligentes y busca identificar posibles señales de incendio para facilitar una respuesta oportuna. El sistema deberá respetar la privacidad de los usuarios, evitando recopilar, almacenar o compartir direcciones y datos personales.

## 2. Alcance

Incluye:

- Implementación de una solución de inteligencia artificial para la detección de humo.
- Identificación de posibles señales de incendio.
- Orientación a la prevención de incendios dentro de edificios inteligentes.
- Consideración de los inquilinos como usuarios principales.
- Protección de la información personal de los usuarios.

No incluye:

- Recopilación o divulgación de direcciones personales.
- Almacenamiento o intercambio de datos personales.
- [DATO PENDIENTE] Integración con sistemas de alarmas y sensores existentes.
- [DATO PENDIENTE] Activación automática de sistemas de extinción de incendios.

## 3. Requisitos funcionales

- RF-1: El sistema deberá identificar la presencia de humo mediante inteligencia artificial.
- RF-2: El sistema deberá detectar posibles señales relacionadas con un incendio.
- RF-3: El sistema deberá facilitar la identificación oportuna de situaciones de riesgo para los inquilinos.
- RF-4: El sistema deberá proporcionar información relacionada con posibles detecciones de humo. [DATO PENDIENTE: medio de notificación].
- RF-5: El sistema deberá evitar solicitar o divulgar direcciones y datos personales de los usuarios.

## 4. Requisitos no funcionales

- RNF-1 – Privacidad: El sistema deberá proteger la privacidad de los inquilinos y evitar la exposición de información personal.
- RNF-2 – Confiabilidad: El sistema deberá ofrecer detecciones de humo confiables para contribuir a la prevención de incendios. [DATO PENDIENTE: porcentaje de precisión requerido].
- RNF-3 – Disponibilidad: El sistema deberá estar disponible para identificar posibles señales de humo cuando sea necesario. [DATO PENDIENTE: porcentaje de disponibilidad esperado].
